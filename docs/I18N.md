# Internationalization

## Supported languages

- `zh` - Simplified Chinese (source strings)
- `en` - English (`po/en.po`)

Configuration: `~/.config/fmon/language` (`zh` or `en`). On first run the
language is inferred from `LC_ALL` / `LC_MESSAGES` / `LANG`; Chinese is the
fallback.

## Switching languages

The sidebar bottom has `中文` / `EN`. A switch:

1. saves the language file,
2. replaces the GUI process with `execv`, preserving the current page and theme.

Restarting is intentional: every widget is rebuilt with one gettext locale, so
old and new languages are never mixed in the same window.

## Translation layout

- `po/fmon.pot` is the marked-string template.
- `po/en.po` contains marked strings plus historical raw UI strings.
- `src/gui/support/i18n_ui.c` translates GTK constructors, labels, tooltips,
  formatted text, Cairo text, file dialogs and alert dialogs at the UI boundary.
- `src/gui/support/i18n_phrases.c` is generated from `po/en.po` and provides a
  longest-phrase fallback for strings composed from several fragments.

## Verification

    ninja -C build
    meson test -C build --print-errorlogs
    tests/check_translations.py .

For a development run without installing:

    LANGUAGE=en FMON_LOCALEDIR="$PWD/build/po" ./build/src/gui/fmon-gui

`FMON_LOCALEDIR` is a test-only override; installed builds use the configured
`LOCALEDIR`.
