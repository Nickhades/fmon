# fmon 全面测试计划

## 1. 测试目标

1. 数据真实性：无伪造、无补零、无平滑假过渡
2. 长时间运行稳定性
3. GTK4 生命周期与引用计数安全
4. 进程页高并发刷新/排序/右键操作安全
5. 长历史与实时数据切换一致性
6. 响应式布局与终端视觉规范
7. root daemon 与普通用户 GUI 的边界

## 2. 测试环境

- FreeBSD 15.1-RELEASE-p7
- clang 19
- GTK 4 + Cairo
- 普通用户 GUI，root daemon
- 分辨率：1304×760、1500×920、1920×1052
- 桌面：X11/Xfce，至少一次其他 WM 冒烟

## 10. 崩溃与 core 流程

1. 保留 core：kern.corefile=%N.core
2. 记录运行二进制与构建时间
3. lldb -c core -f binary
4. 提取全部线程 backtrace
5. 定位到本项目栈帧
6. 修复后重复同样压力测试
7. 压力测试使用 G_DEBUG=fatal-criticals

要求：不能只看没有崩，还要检查 GLib critical/warning。
